# Vasavi Offset Printers

Editorial-style corporate homepage for Vasavi Offset Printers, Kalaburagi.

## Run locally

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

The homepage is composed in `app/page.tsx`, with responsive styling in `app/home.css` and reusable navigation, reveal, and Google rating components under `components/`. Replace the explicitly illustrative Unsplash image URLs in `app/page.tsx` with approved Vasavi product photography when available. Real storefront and showroom photographs provided for this project are in `public/images/`.

The listed establishment year (1968) is marked for owner confirmation. The review card displays the supplied public rating and count, and links to Google without reproducing unverified review text.
